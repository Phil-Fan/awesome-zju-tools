本项目聚焦能够提高 ZJUers 学习、科研与生活效率的工具、脚本、资源与模版，欢迎贡献！

你可以参照 [贡献指南](https://github.com/Phil-Fan/awesome-zju-tools/blob/main/.github/CONTRIBUTING.md) 提交 Pull Request，或在 Issues 中推荐。

如果项目对你有帮助，⭐ Star 一下以支持项目更新！

- 仓库：https://github.com/Phil-Fan/awesome-zju-tools
- 讨论：https://www.cc98.org/topic/6320896

## 内容约定

- 增删资源以 README / 本站分类表格行为单位
- 非 ZJUer 开发或管理的资源请标注 ※
